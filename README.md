# LCA-NodeJS-Exercises
## Course 2 - Backend Web Development
### Exercise 01: Express Server and Routing

### Overview
This project is a Node.js + Express.js REST API built for LCA Week 2 Exercise 01.
The server manages two resources: `Products` and `Employees` with full CRUD operations.
No database is required - routes return descriptive JSON messages.

### Technologies Used
- Node.js
- Express.js

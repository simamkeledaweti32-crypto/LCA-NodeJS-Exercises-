# LCA Week 03 Exercise 03 - Node.js + Express + MySQL

This project is a RESTful API built with Node.js, Express, and MySQL using MVC architecture.

## Features
- CRUD operations for Products and Employees
- MySQL database connection using mysql2
- MVC folder structure: Models, Views, Controllers
- Environment variables with dotenv

## Tech Stack
- Node.js
- Express.js ^4.18.2
- MySQL2 ^3.6.0
- Dotenv ^16.3.1

## How to Run
1. Clone the repo and go to `week03_ex03_node_express` folder
2. Run `npm install` to install dependencies
3. Create `.env` file with your DB credentials
4. Run `npm start`
5. Server will run on http://localhost:3000
